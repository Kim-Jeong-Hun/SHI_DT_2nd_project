수주용량과 CSV 지표 보기

여러 지표를 표준화해 비교하거나, 원하는 지표 하나를 원값 그대로 봅니다. 새로 추가된 CSV와 컬럼에는 NEW를 표시합니다.

실제 날짜 보기
0개월 이동
0개월(이번달 데이터 있어야함)1개월(1달전 데이터 있어야함)2개월(2달전 데이터 있어야함)3개월(3달전 데이터 있어야함)4개월(4달전 데이터 있어야함)5개월(5달전 데이터 있어야함)6개월(6달전 데이터 있어야함)

수주량 선은 실제 날짜에 고정합니다. 슬라이더를 한 칸 옮길 때마다 비교 CSV 선만 원자료 날짜에서 오른쪽으로 1개월 이동합니다.

비교 보기에서는 수주용량과 각 비교 컬럼을 전체 관측기간에서 개별적으로 최솟값 0, 최댓값 1로 변환합니다. 노란색 3개월 구간은 드래그하거나 시작월·종료월을 바꿔 이동할 수 있으며 축은 바뀌지 않습니다. 결측치는 채우지 않습니다.

단일 보기에서는 선택한 변수 하나만 표시하며 표준화하지 않습니다. Y축과 마우스 값은 원자료 값입니다. 결측치는 채우지 않습니다.

즐겨찾기한 변수 0개

각 변수 칩 안의 별표로 저장합니다. 목록을 누르면 해당 CSV와 변수를 다시 엽니다. 즐겨찾기는 이 브라우저에 저장됩니다.

표시할 컬럼

노란 구간은 드래그해서 이동하는 3개월 구간입니다. 위의 칩이 각 선의 색상과 표시 여부를 나타냅니다.
