[A21 · 10/08] 기조 논의 안건 — 외생 충격 · 이상 국면에 강한 수주 예측 (분석 검토, 팀 코드 미수정)

요약
- 지침 규칙 그대로(T-3 정보 → 다음 분기 합, 분기 WAPE, 검증 2022~24 · 평가 2025/2026) 5선종에서 대안을 비교했습니다.
- 결론 ① 국면에 따라 모델 · 기준선 비중을 바꾸는 방식은 효과 없음 — 어느 구성 요소도 급등 '규모'를 몰라서. ② 효과가 가장 큰 건 '정보 신선도': 수주 월보는 실제 공표 시차가 중앙 14일 · 최대 30일인데 지금은 3개월 늦은 값을 씀 → 1개월 시차로 쓰면 고정 결합 기준 검증 0.525 → 0.483, 2025 0.603 → 0.556, 2026 0.407 → 0.339.
- 회의에서 정할 것: 공표 시차가 확인된 자료(수주 월보 · 운임 · GPR)에 '실제 공표 시차' 예외 적용 여부, 기준선에 '최근 3개월 + 최근 3년 평균' 추가, 최종 예측 = 모델 + 기준선 결합.

상세
- 비교 (5선종 평균 분기 WAPE, 검증 / 2025 / 2026): 고정 등가중(모델+두 기준선) 0.525 / 0.603 / 0.407 · 국면 전환 결합 0.525 / 0.604 / 0.408(검증이 고른 비중 = 등가중) · 성과 기반 동적 비중 0.541 / 0.606 / 0.413 · 조짐 시 1.2배 상향 0.526 / 0.593 / 0.385.
- 이상 조짐 지표(선종 운임 2년 중앙값 +30% 또는 3개월 +30%, 수주 3개월이 12개월 평균의 1.5배): 켜졌을 때 실제 > 예측 비율 검증 66% · 평가 77%(꺼졌을 때 50% · 59%) → 방향은 맞히지만 규모는 모름. 유조선은 운임 즉시 공표 기준으로 2025-09에 켜졌으나 다음 분기 실제 1,916만~3,127만 DWT를 모든 방법이 450만~600만으로 예측.
- 해석: '선행 데이터 과적합'보다 '학습 기간(2015~2024)이 평온기라 급등 사례가 없음'이 핵심.
- 이상 국면 예측에 필요한 구성 요소: ① 정보 신선도(실측, 위 수치) ② 수익성 변수 — 1년 용선료 ÷ 신조선가, 중고선가 ÷ 신조선가(확보 필요) ③ 교체 수요 저수지 — 노후선 비율 · 수주잔량/선대(선령 = 과제 ①) ④ 2003~2008 호황기 표본 확보 ⑤ 통합 학습은 선종별 모델링 기조와 달라 드랍.
- 서비스: '수주 국면 경보'를 지침 7절에 추가 — 점 예측은 그대로, 선종별 주의 · 경보 + 위쪽 위험 + 적중률 · 오경보율 공개. 지표 · 기준치는 회의에서 결과 보기 전에 고정.
- 정정: 1차 검토(오전)는 검증에 2025년을 넣었음 → 지침대로 2022~24로 다시 계산해 위 수치로 대체(방향 동일).
- 주의: 비교 모형(M1 · M2)은 팀 모델과 같은 구조의 단순 대리 모형이라 팀 모델 수치와 직접 비교 불가 — 제안 효과는 민규 님 코드에서 재현 필요.
